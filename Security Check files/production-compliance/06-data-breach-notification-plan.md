# Data Breach Notification Plan — Midnight Stories

**Last Updated:** July 30, 2026

---

## 1. Notification Thresholds & Deadlines

- **GDPR Supervisory Authorities**: Notify within 72 hours of breach confirmation if personal data risks rights of individuals.
- **Affected Users**: Notify without undue delay via registered user email or emergency admin site banner.
- **Security Contact**: `security@midnightstories.dpdns.org`

---

## 2. Emergency Broadcast Channel

Admin panel (`/admin`) provides direct bulk messaging capabilities to dispatch official admin alerts and security notices to all registered user accounts.
