# Cookie Notice — Midnight Stories

**Last Updated:** July 30, 2026

This notice explains how Midnight Stories uses cookies and functional storage on https://midnightstories.dpdns.org.

---

## 1. Cookie & Local Storage Categories

| Category | Purpose | Can be disabled? |
|---|---|---|
| **Strictly Necessary** | Session management, login security (`HttpOnly` JWT tokens, CSRF protection) | No — required for the Service to function |
| **Preferences** | Theme choice (`data-theme`), banner dismissal states | Yes |
| **Analytics** | None used — platform does not track individual users across web | N/A |
| **Marketing** | None used — zero ad networks or tracking pixels | N/A |

---

## 2. Your Consent Choices

When visiting the platform, a floating Cookie Consent Banner allows you to:
- **Accept All**: Enables theme and preference retention.
- **Reject Non-Essential**: Restricts storage to essential operational items only.

You can modify your preferences at any time via the **Cookie Settings** link in the website footer or by calling `window.openCookieSettings()`.
