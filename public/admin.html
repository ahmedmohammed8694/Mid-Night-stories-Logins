Business Intelligence Integrations

Enterprise Reporting

Connect your Midnight Stories CRM data to Power BI using the REST API endpoint below. Import and build interactive reports.

Auth Header: x-admin-token: YOUR_ADMIN_JWT

Google Looker Studio
Free BI Platform

Use Looker Studio Community Connector or import JSON/CSV exports to build dynamic charts and share reports publicly.

https://midnightstories.dpdns.org/api/admin/helpdesk/tickets
Method: GET + x-admin-token header
🔗 Open Looker Studio
🛠️ Quick Integration Steps
Power BI Steps:
  1. Open Power BI Desktop → Get Data → Web
  2. Paste the API endpoint URL
  3. In Advanced options, add Header: x-admin-token
  4. Transform JSON → Load to Model
  5. Build visuals and publish to Power BI Service
Looker Studio Steps:
  1. Click "Download CSV Report" button above
  2. Open Looker Studio → Create → Report
  3. Add Data → File Upload → Select your CSV
  4. Build charts (Donut, Bar, Line, Table)
  5. Share public link for team access
